01 / PERSONAL PROJECT

Saldo

Finance, with a little more clarity.

A personal finance dashboard that turns transactions into a monthly overview. Built as a learning project with React, responsive CSS and browser-local storage.

  • React
  • JavaScript
  • CSS
  • REST API
Live demo ↗ (opens in a new tab)View code ↗ (opens in a new tab)
A closer look at the project +

The problem

A list of transactions can be hard to interpret. The goal was to make monthly income, spending and savings easier to understand at a glance.

The experience

A month selector controls the overview. Search and category filters narrow down the transaction list. CSV export makes the visible records portable.

The implementation

React manages the interface state, localStorage keeps transactions between visits, and a Frankfurter API integration provides reference currency conversions with loading and error states.

Scope & next steps

A personal portfolio project using fictional financial data, with no bank connection or account system. Next steps include transaction editing and deeper usability testing.

02 / PERSONAL PROJECT

Estúdio

From idea to done, with a clearer flow.

A task management application with a four-stage kanban board. Create and edit tasks, search and combine filters, and move cards between stages using drag-and-drop or a keyboard-friendly selector.

  • React
  • JavaScript
  • CSS
  • localStorage
  • Drag & drop
Live demo ↗ (opens in a new tab) View code ↗ (opens in a new tab)
A closer look at Estúdio +

The problem

Tasks become harder to follow when status, priorities and deadlines are scattered. The board brings that context into one place.

The experience

Four stages make progress visible. Labels communicate priority and overdue status with text as well as colour. A move selector provides an alternative to dragging.

The implementation

React manages task state and derives the filtered view. Changes are saved locally in the browser. Moving a task updates its status while preserving its other details.

Scope & next steps

A portfolio application with fictional tasks, predefined projects and no shared accounts or real-time collaboration. Next steps include dynamic project management, card ordering and more interaction testing.
